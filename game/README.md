# DropZone — 3D Game Prototype

This is an original Fortnite-style battle-royale prototype built to run in a browser, so it can be tested on a Chromebook without installing Unreal Engine.

## Play

Open `game/index.html` in a modern browser. The prototype uses Three.js from a CDN.

### Controls
- WASD — move
- Shift — sprint
- Space — jump
- Mouse — aim and shoot
- Q — build a temporary wall

## Current systems

- Third-person 3D player
- Stylized island with trees and structures
- Training bots with movement and shooting
- Health + shield
- Weapons/projectiles
- Eliminations and victory state
- Shrinking storm zone
- Temporary build walls
- Responsive camera and pointer-lock aiming
